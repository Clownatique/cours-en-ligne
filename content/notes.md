Définition: Une Base de Données (BD) est une collection de données électroniques stockées de façon pérenne et reliées entre elles par un contexte applicatif. 

Entité : Une "chose" du monde réel qu’on cherche à modéliser 
Entité faibles: Une entité est entité faible si elle peut pas exister sans une autre
Entités spécialisées 

Association : Une relation entre deux ou plusieurs entités. 

Cardinalité: Connectivité(1-n)/Participation(0-1)

Attribut: Propriété d’une entité ou d’une association prend ses valeurs dans un domaine de valeurs de type simple (caractère, chaîne de caractères, entier, date)(ou type complexe, c note *)
